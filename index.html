macOS Setup

Setting up on macOS takes a minute.

ytDownloader is not signed, so macOS needs a quick Terminal nudge. Run these two commands after installing the .dmg.

1

Flag the app as safe

Because this package is not signed, you'll need to flag it safe via Terminal. Drag the YTDownloader.app to your Applications folder first.

Terminal
# Flag the community-signed app as safe
$ sudo xattr -r -d com.apple.quarantine /Applications/YTDownloader.app
2

Install the dependency via Homebrew

Ensure you have dependency support via Homebrew. If you don't have Homebrew, install it from brew.sh first.

Terminal
# Install yt-dlp via Homebrew
$ brew install yt-dlp
That's it. After both commands finish, launch ytDownloader from your Applications folder or Launchpad.
